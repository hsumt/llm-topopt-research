# Results: open ATO cascade on the stress-constrained L-bracket

Branch `experiment/L_bracket_ATO`. Run 3 epochs, low-fidelity tier,
outcome **resolved = True**.

Every number here is read from `open_ato_run.json` in this folder. No verdict, tier, or
design state was written by hand: candidate edits were generated by a model at run time,
the operations that realise them were written by a model at run time, and every verdict
comes from re-solving with the verified solver.

## What the run did

| epoch | applied | how it was authorised | tier | peak, in-plane | peak, out-of-plane |
|---|---|---|---|---|---|
| 1 | `add_out_of_plane_hand_load_case` | disclosure_step | T2 | 606 MPa OVER | not representable |
| 2 | `set_thickness_to_stock_bound` | authority_adopted | T3 | 3794 MPa OVER | 6122 MPa OVER |
| 3 | — | every predicate quiet | — | **61 MPa within** | **48 MPa within** |

Allowable is 350 MPa throughout. The stated problem converged, satisfied its mass budget,
and was 1.73x over yield in plane while carrying no
out-of-plane load at all.

**Epoch 1.** Four predicates fired, including `unrepresented_load_axis` — a
specification-completeness check against the declared intent, which no field measurement can
detect, because a load nobody applied leaves no trace in any stress field. Five hypotheses
were generated *without the operation catalogue in the payload*. Four were gaps that no
existing tool could express; the synthesis stage wrote
`add_out_of_plane_hand_load_case`, `switch_to_extruded_3d_model`, `add_out_of_plane_hand_load_case`.
Applying the load case cleared the completeness anomaly.

**Epoch 2.** With the out-of-plane load now representable, the design is
**17.5x the allowable and 100% of
material is over yield**. That overstress was always present; the specification could not
express it. Synthesis wrote `set_initial_thickness` and `set_thickness_to_stock_bound`.
`set_thickness_to_stock_bound` **survives alone** — 12 of 25 discharged edit sets
survive, and it is the only surviving singleton. It is graded **T3, intent-altering**, so the
cascade applies nothing on its own authority and refers it to the authority stage.

**Authority.** The intent document states that plate thickness is the designer's choice with
stock from 1 to 20 mm. On that written ground the edit was **adopted** — authority derived from
the engineer's document, not from the model's judgement of what seems reasonable. Had the
intent been silent, the ruling would have escalated regardless of how sensible the change looks.

**Epoch 3.** Peak 61.4 MPa in plane and
48.4 MPa out of plane, mass fraction
0.300 unchanged (the budget is a fraction of the domain, which
scales with thickness). Every predicate quiet.

## What the safety mechanisms actually caught

These are measured in this run, not asserted:

- **Written code is gated, but the gate did not fire in this run.** 1 of 6 synthesis
  attempts was not admitted, and it was **not** a gate rejection: the writer returned a
  payload with no `apply_source` field and the attempt failed while being parsed
  (`rejected_because = "unexpected KeyError: 'apply_source'"`). **No record in this run
  shows the AST gate rejecting anything**, so this run is not evidence that it works. The
  gate's restrictions — a synthesized operation may only mutate the specification; no
  filesystem, network, `eval`, `getattr`, dunder access, or computation of a physical
  quantity — were checked separately against nine adversarial sources during development,
  which is bench evidence, not run evidence. The reason the restriction matters is
  unchanged: if written code could compute or assert anything, an agent could influence
  its own verdict.

## Limitations — read before extending

- **The design-intent document was drafted by the agent, not by the engineer.** Every clause in
  `project/experiments/lbracket/intent_lbracket.json` — the 1-20 mm stock range, the fixed
  envelope, both firmness flags, and the out-of-plane service condition itself — is an assumption.
  This is the load-bearing caveat on the whole run: the authority stage adopted an intent-altering
  edit on the strength of that document, so **the adoption in epoch 2 rests on an unconfirmed
  authorisation.** The mechanism is demonstrated; the specific diagnosis is not signed off.
- **The discharge-coarsening precedence bug was fixed after this run.** The mesh override was
  applied after the candidate edits, so a mesh-refining candidate would have had its own edit
  silently overwritten and its verdict would answer a different question. **Checked against this
  record: no candidate in either epoch touches the mesh, so 0 of the 39 discharges here are
  affected** and no verdict in this folder needs re-running on that account. The fix matters for
  future runs, where a mesh-refinement hypothesis is likely.

- **Verdicts were discharged at a coarser mesh than the designs.**
  20 cells per side against
  40 for the baseline and for every
  accepted design state. The predicates are relative measures and reasonably mesh-robust, but a
  verdict is a weaker claim than the design it concerns. Re-run with `--discharge-n-cells 40` to
  remove the approximation.
- **Two layers through the thickness understate out-of-plane stress.** Trilinear hexes
  shear-lock in bending; measured on the solid bracket, peak von Mises at the same load rises
  248 -> 662 -> 949 -> 1096 MPa for 1, 2, 4, 8 layers. The out-of-plane numbers here are
  therefore a *lower bound* on severity. The epoch-3 result at 20 mm has a large margin
  (48 MPa against 350), so the conclusion is unlikely to reverse, but the specific value would move.
- **The out-of-plane load magnitude is UNBOUND.** Nothing in the specification determines it;
  the value used came from the generator as a probe. A design qualified against a probe load is
  not qualified.
- **The benchmark does not reproduce the published tables.** See `RESULTS_L_bracket_ATO.md`
  section 2a: at the paper's own discretisation, compliance is roughly half the published value
  and the formulation ordering differs. Mechanism-level agreement (a stiffness-optimal design puts
  material in the re-entrant corner; stress constraints move it out) is qualitative only.
- **The generator needed prompting to consider thickness.** Across two earlier runs it proposed
  layer counts, aggregation exponents and spatially varying reinforcement without once proposing
  a thicker plate, though the intent declares thickness free and out-of-plane stress scales as
  the inverse square of it. The run above includes a bookkeeping line naming intent-permitted
  quantities no hypothesis has yet proposed. That is bookkeeping over the intent document, but it
  is a nudge, and the unprompted behaviour is the honest baseline.
- **One reproducibility caveat.** The hypothesis set differs between runs. The arc above has been
  observed once end to end; earlier runs with the same code terminated unresolved for the reasons
  listed above. Treat the mechanism as demonstrated and the specific path as one sample.

## Reproducing

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
python -m project.experiments.lbracket.run_open_ato \
    --fidelity low --max-epochs 5 --max-subset-size 3 \
    --discharge-max-iter 80 --discharge-n-cells 20
```

Model usage for this run: 3 epochs through platform model access (`claude-sonnet-5`). Nothing was billed to `ANTHROPIC_API_KEY`;
see `RESULTS_L_bracket_ATO.md` section 7 for why, and for the one-call check that validates
the key path before a real run.
